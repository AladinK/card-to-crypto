Run the sandbox locally

Requires Node.js 22 and PostgreSQL 16. Sandbox mode moves no real money.

git clone https://github.com/AladinK/card-to-crypto.git
cd card-to-crypto
npm install
cp .env.example backend/.env        # fill in the secrets, see docs/DEPLOYMENT.md
npm run migrate -w @cardcrypto/backend
npm run dev:api -w @cardcrypto/backend
npm run dev:worker -w @cardcrypto/backend
API_URL=http://localhost:3000 npm run demo -w @cardcrypto/backend
